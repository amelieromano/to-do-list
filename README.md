# My To-Do List

A simple, pink to-do list app in a single HTML file. It uses only HTML, CSS and plain JavaScript, so there's nothing to install.

## Features

- Add tasks with the **Add** button or by pressing **Enter**
- Tick a task's checkbox to mark it done (it gets crossed out)
- Delete a task with the **×** button
- See how many tasks are left
- Tasks are saved in your browser (`localStorage`), so they're still there after a refresh
- Centred layout that works well on phones
- Pink theme with the EB Garamond font

## How to use

Download or clone the repository, then open `index.html` in any web browser:

```bash
git clone https://github.com/amelieromano/to-do-list.git
```

Then double-click `index.html`.

## Notes

- Tasks are stored per browser and per device, so your phone and laptop each keep their own list.
- The EB Garamond font loads from Google Fonts. Without an internet connection, the app falls back to Garamond or Georgia.
